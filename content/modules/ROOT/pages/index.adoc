Welcome to the Praxis on OpenShift AI workshop!

link:https://github.com/praxis-proxy/praxis[Praxis^] is an open source framework for building proxy servers, written in Rust. link:https://github.com/praxis-proxy/ai[Praxis AI^] is an AI gateway built on it. In this workshop you run both on Red Hat OpenShift AI, in front of echo servers and simulated large language models (LLMs) served by OpenShift AI model serving.

== What you'll learn

In this workshop, you will:

* Understand how Praxis turns YAML configuration into a filter pipeline
* Route, load balance, rate limit and health-check traffic with Praxis core
* Change gateway behavior live by editing a ConfigMap, with no restart
* Serve simulated models with OpenShift AI as KServe InferenceServices
* Route OpenAI and Anthropic API traffic to those models by the model named in the request
* Measure tokens and time to first token per model in OpenShift monitoring

== Who this is for

This workshop is designed for platform engineers and architects who want to understand Praxis and how it can serve as an AI gateway in front of models on OpenShift AI.

**Experience level**: Intermediate

== Prerequisites

Before starting this workshop, you should have:

* Comfort with the `oc` command line and basic Kubernetes objects (pods, Services, ConfigMaps)
* A general idea of what a reverse proxy does
* Some familiarity with LLM APIs such as OpenAI Chat Completions, and with OpenShift AI model serving (helpful, not required)
